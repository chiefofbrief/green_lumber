### 2026-11-19 | Mandiant: China-Linked Hackers Exploited VMware Zero-Day
*30 articles in cluster*

Google and Mandiant say China-linked espionage group Armory Castle exploited the critical VMware vCenter authentication-bypass flaw CVE-2026-123890 (CVSS 9.8) for more than two months before Broadcom patched it. The attackers reportedly gained entry through a separate BeyondTrust Remote Support zero-day, then used a custom tool to steal vCenter data and signing material, create an administrator account, forge authentication tokens and install backdoors. The flaw can give a remote attacker administrative access to vCenter, which manages an organization’s virtual infrastructure; researchers confirmed a small number of compromises and suspect others may also have been affected. Broadcom has released fixes for supported versions, including vCenter 8.0 U3m and 9.0.2.0200, and says there is no workaround; vSphere 7.0 fixes require extended support. Organizations are urged to assess exposure, apply available updates and investigate for compromise because control of vCenter can put the broader managed environment at risk.

**Key Points:**
- Broadcom’s advisory says the vulnerability is reachable whether or not Enhanced Linked Mode is configured. ESX itself is not affected, and the advisory’s flaws do not allow an attacker to run code on an ESX host from inside a guest virtual machine.
- The exposure extends beyond standalone vCenter: the affected software also ships in VMware Cloud Foundation, vSphere Foundation and Telco Cloud products, as well as end-of-support vSphere versions 6.5, 6.7 and 7.0.
- Google said Mandiant had evidence Armory Castle knew about CVE-2026-123890 before a separate vCenter authentication-bypass flaw, CVE-2026-59309, was disclosed on July 29, 2026. The attackers also used Bonesaw against a server already patched for that separate flaw.
